# AI-Based Agri Bot System

## Overview

AI-Based Agri Bot is an intelligent smart farming rover designed to automate agricultural monitoring and assist farmers through Computer Vision, Machine Learning, IoT, and autonomous navigation technologies.

The system performs real-time crop and weed detection, environmental monitoring, and intelligent decision-making to improve farming efficiency and support precision agriculture.

## Features

* Real-time crop and weed detection
* Computer Vision-based field monitoring
* Autonomous navigation using LiDAR and sensor fusion
* IoT-enabled environmental monitoring
* Intelligent decision-making for precision farming
* Remote monitoring and automation

## Dataset

Custom agricultural dataset containing approximately 5,000+ crop and weed images collected from agricultural environments.

Additional LiDAR and sensor data were used for autonomous navigation and real-time field monitoring.
